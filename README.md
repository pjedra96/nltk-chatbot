# Description
This project contains a chatbot web application, which has been developed using a 64-bit version of the Python programming language. The program mainly uses the NLTK library, and contains a chatbot-nltk-corpus.txt, which has no vocabulary in it. The project is a startup.

# System & Package Requirements
- 64 bit operating system (ideally)
- Python version 3.6 - 64 bit (ideally)
- All packages contained in the requirements.txt file
